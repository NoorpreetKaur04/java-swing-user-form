# Java Swing User Registration Form

A simple desktop UI application built with **Java Swing**. This project demonstrates core GUI design principles, input validation and event handling.

----

**Preview:**

----

**Features:**
* _Layout Management_: Combines nested sub panels using 'BorderLayout' and 'GridLayout'.
* _Input Validation_: Checks for empty or placeholder-default inputs on required fields.
* _Selection Management_: Uses 'ButtonGroup' to ensure single-choice behavior for JRadioButton options.

----

**Tech Stack Applied:**

* _Language_: Java (java 21.0.8 2025-07-15 LTS)
* _GUI Toolkit_: Java Swing & AWT
